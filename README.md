# Scout Board — ИИ-разведчик данных

Веб-панель собирает публичные новости из бесплатного GNews, показывает их таблицей и честно останавливается, если запрос неясный или невыполнимый.

Запуск с нуля занимает меньше 10 минут.

## Куда вставить ключ GNews

1. Откройте папку `C:\Users\Honor\Desktop\ScoutBoard`.
2. Найдите файл `.env` (если его нет — скопируйте `.env.example` и назовите копию `.env`).
3. Откройте `.env` в Блокноте.
4. Найдите строку `GNEWS_API_KEY=`.
5. Вставьте ключ сразу после знака `=`. Без кавычек и без пробела.
6. Сохраните файл.
7. Если чёрное окно сервера уже открыто, нажмите в нём `Ctrl+C` и запустите сервер снова. Пока окно не перезапущено, новый ключ не подхватится.

Ключ языковой модели лежит в строке `OPENAI_API_KEY`. Это ключ курса (ProxyAPI). Его тоже нельзя выкладывать в GitHub и присылать в чат.

Файл `.env` в репозиторий не входит. В репозитории только `.env.example` с пустыми значениями.

## Запуск на Windows

Откройте PowerShell:

```powershell
cd C:\Users\Honor\Desktop\ScoutBoard
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Окно не закрывайте. В браузере откройте http://127.0.0.1:8000

Остановить сервер: в этом же окне `Ctrl+C`.

Если PowerShell пишет, что скрипты запрещены, активировать `.venv` не обязательно. Команды выше вызывают Python по полному пути и работают без активации.

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `GNEWS_API_KEY` | Ключ бесплатного GNews |
| `OPENAI_API_KEY` | Ключ языковой модели с курса |
| `OPENAI_BASE_URL` | Адрес ProxyAPI: `https://api.proxyapi.ru/openai/v1` |
| `OPENAI_MODEL` | `gpt-4o-mini` |
| `LLM_TEMPERATURE` | `0.2` |
| `DATABASE_PATH` | Файл SQLite, по умолчанию `data/scout.db` |

## База и аудит

База — один файл `data/scout.db`. Его не нужно ставить отдельно.

Таблицы: `datasets`, `records`, `agent_runs`, `audit_runs`.

Посмотреть журнал в панели: вкладка **Аудит**.

Посмотреть число записей аудита из PowerShell, пока сервер запущен или остановлен:

```powershell
.\.venv\Scripts\python.exe -c "import sqlite3; c=sqlite3.connect(r'data/scout.db'); print('audit', c.execute('select count(*) from audit_runs').fetchone()[0]); print('review', c.execute('select count(*) from agent_runs where needs_review=1').fetchone()[0])"
```

## Примеры запросов

В PowerShell нужна команда `curl.exe`, не `curl`. Иначе сработает другая команда и примеры сломаются.

Создать набор:

```powershell
curl.exe -X POST http://127.0.0.1:8000/datasets -H "Content-Type: application/json" -d '{"name":"Новости недели","source":"GNews"}'
```

Спланировать нормальный запрос:

```powershell
curl.exe -X POST http://127.0.0.1:8000/ai/plan_and_collect -H "Content-Type: application/json" -d '{"query":"Собери новости за последние 24 часа по запросу «ноутбук» и сохрани поля title, date, source, url"}'
```

Ручная проверка, сбор не должен стартовать:

```powershell
curl.exe -X POST http://127.0.0.1:8000/ai/plan_and_collect -H "Content-Type: application/json" -d '{"query":"Собери самое важное"}'
```

В ответе будет `"needs_review": true` и `"confidence": "low"`.

Собрать новости (подставьте `dataset_id` из первого ответа):

```powershell
curl.exe -X POST http://127.0.0.1:8000/datasets/ВСТАВЬТЕ_ID/collect -H "Content-Type: application/json" -d '{"query":"Собери новости за последние 24 часа по запросу «ноутбук» и сохрани поля title, date, source, url"}'
```

Открыть витрину:

```powershell
curl.exe "http://127.0.0.1:8000/datasets/ВСТАВЬТЕ_ID/records?limit=50"
```

## Как воспроизвести ручную проверку

Файл `tests_data/queries.jsonl`: 7 корректных запросов, 2 двусмысленных, 1 невыполнимый.

Двусмысленные:

- `Собери самое важное`
- `Собери данные по рынку и сделай вывод`

Невыполнимый:

- `Собери закрытую статистику по всем конкурентам за год`

Проверка без браузера:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

В панели вставьте двусмысленный запрос, нажмите **Спланировать**. Должен появиться блок «Нужна ручная проверка», а кнопка **Собрать** останется серой.

## Что делает контроль качества

`POST /ai/plan_and_collect` вызывает языковую модель и просит строгий JSON. Отдельно правила курса проверяют запрос:

- нет темы в кавычках или нет ограничения — ручная проверка;
- «самое важное», «по рынку», «сделай вывод» — ручная проверка;
- закрытые данные, конкуренты, период больше 30 дней — ручная проверка, GNews не вызывается;
- тема и ограничение есть — сбор разрешён, в витрину попадают только `title`, `date`, `source`, `url`.

Бесплатный GNews: не больше 10 статей, задержка около 12 часов, история 30 дней. Платный адрес и смена тарифа не используются.

## Docker

Когда файл `.env` уже заполнен:

```powershell
docker compose up --build
```

Панель та же: http://127.0.0.1:8000

Остановить: `Ctrl+C`, затем `docker compose down`.

## Демонстрация

Короткое видео 2–4 минуты, по порядку:

1. Создать набор с именем и источником GNews.
2. Корректный запрос: Спланировать → Собрать → открыть витрину → Скачать JSON.
3. Запрос «Собери самое важное»: блок ручной проверки, кнопка «Собрать» серая.
4. Вкладка Аудит: видны запуски и текст ошибки у ручной проверки.

Защита на 5–7 минут читается по файлу `ОТЧЁТ.md`.
